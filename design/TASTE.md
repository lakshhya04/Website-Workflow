# Taste

## Read this before writing any UI

Before you write markup or CSS for this project:

1. Open every image in `design/references/`. Look at them. Do not skip this.
2. Read `design/tokens.css`. Every value you use must come from it.
3. Read any `*-DESIGN.md` in `design/references/` for component and state rules.

## What this project looks like

- Editorial, not SaaS. Type-led. Big headline, real paragraph, generous air.
- One accent colour. It is used for actions only, never for decoration.
- Whitespace is the design. When in doubt, remove an element and add space.
- Motion explains a change of state. It never announces itself.

## Banned by default

- Gradient text and gradient backgrounds
- Emoji as icons
- Three-column feature card grids with an icon on top
- Drop shadows on anything that is not floating above the page
- `border-radius` above 16px on anything that is not a pill button or an avatar
- More than two font weights on one screen
- Centre-aligned body copy longer than two lines

If a brief genuinely requires one of these, say so and ask first.
